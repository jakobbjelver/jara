# JARA — Just Another Running App

JARA is an opinionated, open-source running app for iOS and Android. It tracks your
runs with GPS, gives you insightful analytics, and helps you understand your progress
over time. Built by the community, for the community.

- **Free.** No ads, no subscriptions, no in-app purchases.
- **Private.** All run data lives on your device. No accounts, no servers.
- **Honest.** No gamification, no artificial rewards, no social network.

## Features

- **Run tracking**: GPS route recording, auto-pause, manual laps, audio cues, background GPS
- **Post-run analysis**: Pace-colored route map, pace chart, elevation profile, splits table
- **History**: Chronological list with search and swipe-to-delete
- **Analytics**: Weekly mileage, pace trends
- **Data portability**: Export/import GPX, TCX, CSV; encrypted backup/restore
- **Themes**: Light, Dark, and named color themes — grayscale-at-rest design
- **Self-improvement loop**: In-app Change Requests become anonymous GitHub issues
